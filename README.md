# AI Mini Projects 🤖

A collection of AI and Python-based mini projects developed as part of a college project.

## 🛠️ Technologies Used

- Python
- Flask
- AI / Generative AI
- HTML
- CSS
- Bootstrap

## 📂 Projects

- AI Study Analyzer
- Flask Weather Application
- Text Generation with AI
- Text Translation with AI

## ✨ Features

- AI-based text generation
- Text translation
- Study analysis
- Weather information
- Web-based interfaces

## 🔐 Security

API keys and environment variables are stored locally in `.env` files and are not included in the GitHub repository.

## 🚀 How to Run

1. Clone the repository.
2. Install the required Python dependencies.
3. Create the required `.env` files locally.
4. Add your own API keys where required.
5. Run the respective Python/Flask application.
